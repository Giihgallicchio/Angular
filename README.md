#  PROJETO — ANGULAR


##  Descrição do Projeto
Projeto desenvolvido durante as aulas de **Angular** na **Faculdade Senac**, com o objetivo prático de consolidar os conceitos básicos do ecossistema do framework e aprender a arquitetar e desenvolver aplicações web modernas.

---

##  Tecnologias Utilizadas

* **Framework:** Angular 
* **Linguagem:** TypeScript 
* **Estrutura & Estilização:** HTML5 & CSS3 

---

##  Objetivo

Desenvolver autonomia e competências técnicas na criação de componentes, gerenciamento de estado, diretivas e rotas com Angular por meio das atividades práticas propostas em sala de aula.

---

##  Como Executar o Projeto

Certifique-se de ter o [Node.js](https://nodejs.org) instalado em sua máquina. Siga os passos abaixo no terminal:

### 1. Instalar as dependências
Baixe todos os pacotes necessários configurados no projeto:
```bash
npm install -g @angular/cli
```

### 2. Iniciar o servidor de desenvolvimento
Execute o comando do Angular CLI para rodar a aplicação localmente:
```bash
ng serve
```

### 3. Acessar a aplicação
Após o servidor iniciar, abra o seu navegador e acesse o endereço abaixo para visualizar o projeto em tempo real:
👉 **[http://localhost:4200/](http://localhost:4200/)**
