# Angular

Projeto desenvolvido durante as aulas de Angular, com o objetivo de praticar os conceitos básicos do framework e aprender a desenvolver aplicações web.

## Tecnologias utilizadas

- Angular
- TypeScript
- HTML
- CSS

## Como executar o projeto

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
ng serve
```

Depois, acesse http://localhost:4200/ no navegador.

## Objetivo

Praticar e desenvolver conhecimentos em Angular durante as atividades em sala de aula Senac.
